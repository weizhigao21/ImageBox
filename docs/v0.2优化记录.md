# v0.2 工作台与稳定性优化

日期：2026-10-14。视觉参考：用户提供的 `G:/code/集成文本生语音程序/UI_STYLE.md`。

## 界面

白色内容区，208 px 浅灰导航，320–352 px 右侧属性栏，中央预览与紧凑队列，78 px 底部操作区。
深色主按钮，橙色细进度条，小圆角与细分隔线；默认 1380×900，最小 1080×720。
预览底色支持棋盘、白底、深色底；长状态省略并保留完整悬停提示。
参数标签放在控件上方，组页整体可滚动，数值框和参数下拉框不响应滚轮修改。

## 稳定性与性能

- 后台整批调用 Pipeline，逐项发出结果；进度不再为每张图片重复 0/1→1/1。
- 读取、推理结束与写出前检查取消；中途取消不作为图片失败记录。
- 关闭窗口时取消处理和下载，使用计时器等线程结束，不阻塞界面或强制结束线程。
- ONNX 的设备选择独立于 Torch；模型加载后根据 session 实际提供者显示运行设备。
- 参数转换验证候选值、数值范围和有限数值。CLI 错误简短报告，预设载入前验证。
- 最近一张的无主体提示原始遮罩可复用，调边缘/输出参数后点处理不会再次推理。模型缓存键包含有效推理参数和模型目录；ONNX 修改简易后端的处理长边不会重建 session。
- GUI 完整结果写入临时 `.npy` 文件，只按需恢复当前图片。原图预览与无修改会话缓存上限为 6；含笔迹或未保存修改的会话保留。CLI 每张导出后释放像素。
- 手工修改始终叠加在 `edit_base_alpha` 上；结果版本变化才把已有笔迹标为需要重存。重复保存、切图和撤销所有笔迹后保存均保持一致。
- 下载先写 `.part`，检查 Content-Length 和非空内容，通过后替换目标；取消/失败清理临时文件并保留原有权重。
- 测试与 CLI 使用 UTF-8 输出，避免默认 Windows 编码无法输出测试 emoji。

## 验证

核心、UI、拖放、结果画笔、原图标记五套原有测试，以及 14 项新增回归测试。
本机简易后端合成样本 IoU 1.000、杂乱背景 IoU 0.914；本地 RMBG-1.4 ONNX 在 CPU 上完成处理。
离屏检查 1380×900 和 1080×720 两种窗口尺寸、空状态、结果状态及边缘参数页。
下载验证使用模拟响应，覆盖中断和长度不足，不会联网下载权重。

## 使用边界

临时结果缓存会使用磁盘空间，正常清空队列或退出时清理。若暂存写入失败，会保留内存结果并记录日志。
正在执行的模型调用不能在任意指令处打断，取消在阶段边界生效；网络下载取消也可能等待读取超时。
本轮没有增加自动实时调参预览、跨启动编辑会话保存、软笔刷、超分或裁剪功能。
