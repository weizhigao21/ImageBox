# 像匣（ImageBox）更新与发布

当前版本由 `src/imgtool/__init__.py` 中的 `__version__` 统一维护，当前为 0.3.0。
更新核心来自用户提供的 `G:/code/py-updater`，副本保存在 `src/pyupdater`，不依赖其他工程的绝对路径。

项目仓库：[weizhigao21/ImageBox](https://github.com/weizhigao21/ImageBox)。
更新及发行版页面：[GitHub Releases](https://github.com/weizhigao21/ImageBox/releases)。

## 使用入口

左侧「检查更新」，或菜单「帮助 → 检查更新」。
在更新窗口填写公开的 GitHub 发布仓库，支持 `用户名/仓库名` 或完整仓库链接，点击保存。
配置保存在程序根目录的 `update_config.json`，默认更新源为 `weizhigao21/ImageBox`。

已配置更新源时，启动约 1.5 秒后后台检查。网络失败只记录日志，发现新版在左侧提示。
可在 `config/settings.json` 设置 `check_updates_on_startup: false` 关闭启动检查。
手动检查显示版本和更新说明，随后下载包。关闭窗口或点击取消可取消下载，线程结束前不会销毁它。

源码运行只检查和下载，不自动替换开发工程；下载后可打开所在目录。
打包后的 `ImageBox.exe` 提供「安装并重启」。有图片任务、模型下载或未保存涂抹时，应先结束/保存后安装。

## 更新与数据保护

下载验证产品包名、字节长度、zip 路径、主程序条目及 CRC。
主程序把更新程序复制到下载缓存后启动，将校验后的配置快照传给独立进程，然后正常关闭。
独立进程等待主程序退出，备份旧程序、替换程序文件，启动新版。
新版启动即退出时恢复旧版，保留更新日志。

始终保留顶层 `config/`、`models/`、`output/`、`logs/` 和 `update_config.json`。
更新包中的同名数据条目不会覆盖用户数据。包不包含模型权重和处理结果；模型首次使用时另行下载。
独立更新日志位于安装目录 `logs/updater.log`。

## 构建

构建工具依赖 PyInstaller：

```powershell
python -m pip install pyinstaller
python tools/build_release.py --repository weizhigao21/ImageBox
```

产物：

- `dist/ImageBox/ImageBox.exe`：像匣主程序。
- `dist/ImageBox/updater.exe`：独立更新程序。
- `dist/ImageBox/update_config.json`：发布仓库配置。
- `dist/ImageBox/README.md`：便携版使用说明及项目地址。
- `dist/releases/ImageBox-v0.3.0.zip`：整个程序目录的更新包。

主程序是 onedir 构建，必须分发整个 `dist/ImageBox` 目录，不能只复制单个 exe。
便携构建包含简易抠图和 ONNX CPU；Torch/BiRefNet 为源码环境中的可选依赖，不纳入此默认构建。
构建缓存放在工程 `build/.pyinstaller-cache`，避免清理其他工程的缓存。
Windows Qt 使用系统 ICU；spec 排除构建 PATH 中 Poppler/Conda 的冲突 ICU DLL。

只构建独立更新程序：

```powershell
python tools/build_release.py --updater-only
```

使用已有可执行产物重新生成发布包：

```powershell
python tools/build_release.py --skip-build
```

## GitHub 发版

1. 在 `src/imgtool/__init__.py` 修改版本号，例如 0.3.1。
2. 构建并验证发布包。
3. 在配置的公开仓库创建 Release，tag 使用 `v0.3.1`。
4. 上传对应的 `ImageBox-v0.3.1.zip`。资源名使用 ASCII，保持产品前缀和版本号一致。

首次分发需下载完整程序目录；包含 updater.exe 后，后续版本可在应用内安装。
在线更新需要在该仓库发布带对应 ZIP 的 Release；仅上传源码不会生成可下载安装的版本。

## 验证

```powershell
python tests/update_test.py
python tests/optimization_test.py
python tools/verify_updater.py
dist\ImageBox\ImageBox.exe --verify-runtime build\runtime.json
```

更新测试覆盖仓库配置、资源选择、下载中断/损坏、源码安装保护、异步界面、冻结路径和失败回滚。
`verify_updater.py` 用真实 updater.exe 在独立临时目录触发新版启动失败，检查用户数据和旧程序恢复；不会更新开发工程。
`--verify-runtime` 离屏验证打包界面、图标、模块发现、图片读写/处理和更新入口，输出 JSON 报告。
