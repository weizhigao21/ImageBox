# 像匣（ImageBox）Windows 便携版

项目地址：[weizhigao21/ImageBox](https://github.com/weizhigao21/ImageBox)

发行版与更新：[GitHub Releases](https://github.com/weizhigao21/ImageBox/releases)

## 启动

将 ZIP 完整解压到一个可写目录，双击 `ImageBox.exe`。需要保留同目录的 `_internal`、`updater.exe` 和 `update_config.json`，不要只移动主程序。

本版提供简易抠图和 ONNX CPU 抠图。简易抠图无需模型；使用 ONNX 时，在参数栏选择权重并下载。超分和裁剪目前为占位模块。

在右侧「任务」添加图片，切换「参数」设置处理方式，点击底部处理按钮。结果可预览和精修，再保存到输出目录。

## 更新与数据

左侧「检查更新」从 `weizhigao21/ImageBox` 的 Release 获取新版。下载完成后点击「安装并重启」；安装前请结束任务并保存涂抹。

应用更新会保留 `config`、`models`、`output`、`logs` 和 `update_config.json`。源码仓库内的改动需要正式发布为带 ZIP 的 Release，才会作为在线更新提供。

模型权重未附带在压缩包中。此默认便携版使用 CPU，不包含 Torch/BiRefNet 后端。
